# 📊 Stock Portfolio Tracker

## CodeAlpha Internship – Task 2

A simple **Stock Portfolio Tracker** developed using Python as part of my **CodeAlpha Internship**.

The program allows users to enter stock names and quantities, calculates the investment value based on predefined stock prices, displays the total investment, and saves the portfolio details into a text file.

---

## 🎯 Objective

The main objective of this task is to build a simple stock portfolio tracker using Python and practice:

* Dictionaries
* Lists
* Loops
* Conditional statements
* User input/output
* Basic arithmetic
* File handling

---

## ⚙️ Features

* Displays available stocks and their prices
* Allows the user to enter multiple stocks
* Accepts the quantity of each stock
* Validates the entered stock name
* Calculates individual investment value
* Calculates total portfolio investment
* Saves the portfolio details into `Portfolio.txt`

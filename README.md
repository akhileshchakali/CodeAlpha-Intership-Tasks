# 📧 Email Extractor

## CodeAlpha Internship – Task 3

A simple **Email Extractor** developed using Python as part of my **CodeAlpha Internship**.

## 🎯 Objective

The objective of this task is to automate the process of extracting email addresses from a text file using Python.

- Regular Expressions (`re`)
- File handling
- Reading text files
- Writing text files
- Lists
- Loops
- String patterns
- Basic task automation

## ⚙️ Features

- Reads email-containing text from `input.txt`
- Searches for email addresses automatically
- Uses Regular Expression to identify email patterns
- Extracts multiple email addresses
- Stores extracted emails in a list
- Saves the extracted email addresses into `emails.txt`
- Displays a success message after completion
